# 🛡️ AI-Powered Fraud Detection System

An intelligent web application that detects fraudulent financial transactions using Machine Learning. Built with Python and Flask, the system predicts whether a transaction is fraudulent and provides an interactive dashboard for analysis.

---

## 🚀 Features

- Real-time Fraud Detection
- Interactive Dashboard
- Transaction Analytics
- Machine Learning Prediction
- Simple and User-Friendly Interface
- Fast Prediction Results

---

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Machine Learning
- Pandas
- NumPy
- Scikit-learn

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Hariramkv/Fraud_Detection_project.git
```

Go to the project folder:

```bash
cd Fraud_Detection_project
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```
